# ResuMatch — Resume Analyzer & Job Recommendation System

Full-stack college project: HTML/CSS/JS + Python Flask + SQLite

## Pages
| Page | URL | Who |
|------|-----|-----|
| Home | / | Everyone |
| All Jobs | /jobs | Everyone |
| Contact | /contact | Everyone |
| Login | /login | Everyone (3 role tabs) |
| Sign Up | /signup | Candidates only |
| Profile Form | /candidate/form | Candidate |
| Recommendations | /candidate/recommendations | Candidate |
| Hiring Dashboard | /hiring | Hiring Team |
| Admin Panel | /admin | Admin |

## Run on Mac
```bash
pip3 install flask
cd resumatch
python3 app.py
# Open: http://localhost:5000
```
